# Parte B
Parte B — Elemento Generativo

Descrição do projeto

Neste projeto, utilizei o p5.js para criar uma composição gráfica generativa. Através de código, defini as formas, as cores e o movimento dos elementos visuais.

Elemento generativo escolhido

Escolhi utilizar quadrados que rodam e se movimentam no ecrã.

Justificação da escolha

Escolhi este elemento porque permite explorar a rotação, o movimento e a repetição de formas geométricas. Através da programação, consigo criar diferentes composições visuais e observar como os elementos interagem entre si.

Tecnologias utilizadas

p5.js

JavaScript

HTML e CSS
